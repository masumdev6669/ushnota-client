# Ushnota - Winter Relief Events Platform

Ushnota is a community-driven event management platform where users can create, join, and track winter relief events (like blanket and clothes distribution) in their local area.

**Live Site URL:** [https://ushnota-client.vercel.app](https://ushnota-client.vercel.app)

## Features

- 🔐 **Secure Authentication:** Email/Password and Google login powered by BetterAuth and MongoDB, with JWT-protected Express APIs.
- 📅 **Event Creation:** Logged-in users can create community events with future-date validation and specific event types.
- 🔍 **Explore Events:** A public, responsive grid showing all upcoming events fetched dynamically from MongoDB.
- 🤝 **Join & Track:** One-click Join functionality. Logged-in users can view all their joined events in a dedicated dashboard.
- ⚙️ **Manage Events:** Event creators have full control to edit or delete their own events.
- 🌗 **Dark/Light Mode:** A seamless theme toggling experience across the entire application.
- 📱 **Fully Responsive:** Mobile-first design ensuring the platform works perfectly on phones, tablets, and desktops.
